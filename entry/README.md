# 宗师杯冬季参赛入口

独立参赛服务与现有 GitHub Pages 静态战报站配套。Cloudflare Worker 接受浏览器提交，D1 保存在服务端。公开页面不提供浏览报名、联系人或队伍列表的接口。

## 开发与验证

需要 Node.js 22.13 或更高版本，测试使用内置 SQLite。无需安装包。

```sh
node build.mjs
node --test test.mjs
node local-preview.mjs 8791
```

本地预览使用 127.0.0.1 和内存库，关闭后丢弃，仅用于合成数据。部署包入口为 `dist/server/index.js`。托管主项目使用 D1 绑定 `DB` 并从 `drizzle/` 应用迁移；Worker 不在请求内建表。站点所有者在 Sites 的环境变量设置可信的 `OPS_OWNER_EMAIL` 或不少于 32 字符的 `OPS_ADMIN_TOKEN`。请仅在提供受信身份标头的 Sites 网关下启用所有者邮箱鉴权。移植到其他主机时必须删除来自外部请求的身份标头。

## 参赛者

- 报名填写姓名或比赛昵称、一个联系渠道、组队方式。已有队长建队后把入队码转给队员；个人可以等赛务组队。
- 私人回执用于跨设备查看或修改本人报名。仅队长可以申报本队五人的北京时间空档、群体和附加赛意向。已分组后，队员都可凭各自回执查看三轮对手和时间。
- 匿名调研独立存储。有单独的回执可撤回。服务不记录学校、生日，公开页面不列报名名单。
- 报名、时段和调研以服务端回执为准。暂时无法确认时可持同一回执重试；同一回执不会新建重复记录。

## 赛务

从 `/admin` 使用主办方账户登录或输入赛务令牌。可私下导出 JSON，将五名散人分为一队并指定队长，或选择四队、检查交集后锁定三轮。默认每轮 120 分钟，实测后可选择 90 分钟。系统检查四队申报的共同空档与三轮不重叠；跨组房间、裁判总量和加时由赛务另行核对。

若本组不同队伍分别填了国内国际高中和海外读书或交换，后台提示潜在交手轮次，供裁判按实际出场再核实。人数未齐或缺少足够共同时间时不确认三轮。数据导出仅供赛事工作人员。

## 视觉素材

首页冬季赛场底图为本次原创插画，五个功能入口使用独立 CSS，移动端自动换行。比赛日期和晋级规则保持候选状态，赛务确认后再更新。
