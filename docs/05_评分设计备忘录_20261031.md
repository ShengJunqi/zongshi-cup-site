# 05 评分设计备忘录（v0.1，2026-10-31）

> 日期：2026-10-31 ｜ 状态：v0.1 待 Codex 审 ｜ 范围：只定用途与边界，**不含公式、不含数值**
> 依据：`docs/01_整体大纲_20261031.md` §5；数据来源与确认状态见 `docs/02_事实与来源清单_20261031.md`
> 一句话：现阶段评分没有实现、也不该对外；先分清「谁回答什么问题」，再谈怎么算。

## 1. 结论先行

1. 评分第一用途是**内部辅助组队与匹配**，不是选队长，也不是荣誉展示。
2. 赛事积分、个人竞技评分、单场表现评价是**三套独立系统**；禁止把 KDA、胜率、参赛次数、人气投票混成一个总分。
3. S1 每人约 1–2 场、S2 主要 1 场，**不足以支持可信的长期实力榜**，连「谁更强」的方向性结论都不该下。
4. 现阶段对外只展示**真实比赛记录**；评分只内部试算，不据此决定队长资格，不公开给选手定级。
5. 评分沿用「稳定标签」纪律：样本不足不公布，不先算再解释。

## 2. 用途先定

| 用途 | 需要什么 | 现阶段 |
|---|---|---|
| 匹配 / 组队（内部） | 相对水平 + 位置 + 可用时间 | **唯一保留**，仅内部试算 |
| 选队长 | 可信排序 + 可申诉规则 | 本轮不启用，资格由 Jason 定 |
| 荣誉展示 | 真实记录、高光、标签 | 用真实记录做，不用评分排名 |

理由：评分一旦决定机会，误差就变成不公；1–2 场时误差大于信号；荣誉展示不需要分数。

## 3. 三套系统必须分开

| 系统 | 回答的问题 | 使用者 | 输入 | 公开 |
|---|---|---|---|---|
| 赛事积分 | 队伍怎样排名、晋级 | 运营、参赛队 | 对阵结果、赛制、阶段 | 可公开（规则确认后） |
| 个人竞技评分 | 个人水平、辅助组队 | 内部组队 | 多场、位置、对手强度 | 内部试算，不公开 |
| 单场表现评价 | 这一场谁贡献了什么 | 观众、本人 | 单场结算与时间线 | 可公开，标「单场」 |

不允许跨系统加总；单场表现不能当个人实力的代理。

## 4. 数据盘点

**可靠**：比分、基地时间、击杀/推塔时间码（A 级）；S1 六维与场次胜率、队伍归属（37 条 / 32 昵称 / 6 队）；标签稳定性（5 组阈值全中才发布）；视频证据。

**缺口**：

- 场次：无同一人的连续多场序列，判断不了稳定性与趋势。
- 身份：5 个昵称跨位置未合并，S2 身份待确认，可能把两人算成一人。
- 位置：S2 分路待确认、口径未统一，位置公平没有前提。
- 口径：六维公式与单位无字段字典，占比类受队友分配影响（见 `docs/04`）。
- 对手：强度、阵容、经济差分层未记录，无法做难度校正。
- 规则：历史赏金赛带速通与 MVP 奖励，S1/S2 非正式赛季，不能混算。
- 异常：掉线、重开、判负、弃赛未标记，无法排除。
- 运营：可参赛时间、组队偏好未采集（由 `docs/06` 第一轮补）。

## 5. 两类评分的局限

**胜负型**：5 人团队项目，胜负受队友与组队方式影响远大于个人，1–2 场基本是噪声；拍卖组队后胜负更多反映组队差异；赛制（BO、速通、MVP 加成）会改变对局目标。

**表现型**：六维多为占比或均值类，受队友分配、位置、局内战术影响；可被刷（保 KDA、蹭参团、刷无效伤害与承伤）；捕捉不到指挥、视野、开团时机、资源置换；单场波动不能外推。

结论：两类都只能作参考，不能单独定级；现阶段连参考都只在内部。

## 6. 不同位置怎么处理

1. 先分位置，不做跨位置统一分；位置未确认前不做跨位置比较。
2. 单场评价按位置选指标，跨位置只在同位置组内讨论。
3. 位置以实际分路为准、人工确认后写入；昵称跨位置先确认身份。
4. 暂不设位置权重，只记录「哪些指标对哪些位置不公平」的待验证清单。

## 7. 怎么避免鼓励刷数据

公开**记录**、不公开**等级**（无分可刷）；场次门槛（样本不足不参与）；原始结算与来源留档、异常波动抽查；异常场次单独标记可排除；报名与昵称绑定；娱乐投票与竞技评分分离；申诉通道入档。

## 8. 新人 / 少场次 / 退赛 / 争议

| 场景 | 处理原则 |
|---|---|
| 首次参赛 | 不参与评分，显示「场次不足」，真实记录照常展示 |
| 少场次 | 仅内部区间参考，不排序、不展示、不进队长讨论 |
| 退赛 / 弃赛 | 保留已发生记录，不推断未发生比赛，标「未完成」，不扣分 |
| 结果争议 | 冻结该场评分，以事实清单为准，结果作记录字段追加，不删原数据，重算留旧版 |
| 身份未确认 | 数据暂不进评分 |
| 数据缺失 | 标「数据不足」，不插值、不猜 |

## 9. 更新与版本记录

三套系统各自独立 `ruleset_id`，比赛规则版本与评分版本分开。每次变更记：版本号、生效范围、内容、理由、批准人、生效时间、受影响场次、试算对比。历史不改写：重算新版本、旧版留档。对外只写「内部试算 v0.x（未公开、未定级）」。发布三条件：样本达标、位置确认、争议关闭。

## 10. 本轮边界

只展示真实比赛记录，不展示评分、等级、排名、实力标签；评分仅内部试算，不决定队长资格、不公开定级、不声称已实现、不含公式数值。

**是否能由现有王者建模项目支持（数据、指标、样本门槛）需向建模会话确认，不能默认已具备；需求见 `docs/07_外部对接需求清单_20261031.md` M4。**
