## 3. 口径定义（写进页面「字段口径」）

- 评分 = 结算面板战斗评分。
- 输出 = 对英雄造成伤害；承受 = 承受伤害；经济 = 获得金币。
- 参团 = (击杀 + 助攻) / 队伍击杀。
- 合计：K/D/A、输出、承受、经济按人相加；参团取人数平均（不可相加）。
- 经济差 = 22.2k − 15.0k = 7.2k（红多 48%）；伤害差 = 142.9k − 89.3k = 53.6k（红多 60%）。
- 面板列名本轮**未逐字录得**：四列顺序按上式推定，并用「输出合计 = 对方承受合计」反向验证（见 §5）。这是推定，不是确证，已进待核实 #7。

## 5. 校验（页面可直接复核）

1. 阵亡对账：蓝 4+3+4+2+4 = 17 = 红击杀 17；红 2+0+1+0+0 = 3 = 蓝击杀 3。
2. 伤害互等：蓝输出 89.3k = 红承受 89.3k；红输出 142.9k = 蓝承受 142.9k（两组各自精确相等）。
3. 参团复算：10 人里 9 人符合 (K+A)/队伍击杀（±0.5 点）；李信面板 64%，计算 64.7%，另一处记 65% → 待核实。
4. 方向校验：红方 17 杀 22.2k 经济、蓝方 3 杀 15.0k 经济，方向不矛盾（只做方向校验，不做因果推断）。
