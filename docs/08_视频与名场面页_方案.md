| 页脚 | 沿用现有 3 行 | 与其他页一致 |

技术约束（有意为之）：
- **无 JS**、无 `<video>`、无 `<iframe>`、无外链图片 → 双击打开零依赖，也不会偷偷播未授权素材；
- 封面用 CSS 占位（虚框 + 片名 + 16:9），不引用任何图片文件，避免「缺图请求」和资产提前入站；
- 页面专属样式放在页内 `<style>`（`.vcover / .vdur / .vmeta …`），**不改** `theme.css`；集成时应搬进生成器 CSS 常量。

## 3. 数据字段（建议契约增量，待 Codex 审）

### 3.1 复用现有契约

- `source_ref_id` → `SourceRef`（`docs/04` §3.12），视频元数据的每个数字都要挂来源；
- `match_id` / `game_id` → 视频必须挂到具体比赛，不挂「大概某场」；
- `person_id` → 切片对应选手（V2 才需要）；
- `publish_status` **不用于视频**：它表达「方案是否获准发布」，与「这段画面能不能公开」不是一回事（沿用 `docs/04` §2 四维度分离原则）。

### 3.2 新增 `Video`（建议实体）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `video_id` | string | 是 | 稳定 ID，`v_0001` 起，不依赖文件名 |
| `title` | string | 是 | 页面标题（可与人读文件名不同） |
| `file_name` | string | 是 | 交付文件名，如 `四分钟复盘_v01.mp4` |
| `duration_seconds` | number | 是 | 秒，保留 1 位小数（57.6 / 57.0 / 118.0） |
| `duration_status` | enum | 是 | `confirmed`（ffprobe 实测）/ `recorded`（他人记录，待复核） |
| `width` / `height` | int/null | 否 | 未知为 null，页面显示「待补」 |
| `aspect` | enum/null | 否 | `16:9` / `9:16` / 其他 |
| `cover_asset` | string/null | 否 | 站内相对路径；null = 渲染占位 |
| `clip_type` | enum | 是 | `review` / `opening` / `promo` / `highlight` |
| `match_id` / `game_id` | string | 是 | 至少一个；`game_id` 优先 |
| `person_ids` | array | 否 | 切片主视角选手 |
| `hero` | string/null | 否 | 若切片聚焦单个英雄 |
| `clip_start_clock` / `clip_end_clock` | string/null | 否 | 游戏内起止（`mm:ss`）；未知为 null |
| `rights_status` | enum | 是 | `cleared` / `pending` / `denied` / `unknown` |
| `rights_parts` | object | 是 | `{music, screen, player_consent}` 各取同上一组值 |
| `display_policy` | enum | 是 | `placeholder` / `linked` / `embedded` |
| `source_ref_id` | string | 是 | 时长 / 内容依据 |
| `notes_internal` | string/null | 否 | 内部备注，**永不渲染** |

### 3.4 生成器校验（违反即构建失败或告警）

1. `rights_status != cleared` → 只能 `display_policy=placeholder`，**禁止**渲染 `<video>` / `<iframe>` / `播放` 按钮；
2. `rights_parts` 三项都 `cleared` 才能升级到 `linked`（外链播放）；
3. `duration_status=recorded` → 页面必须显示「待复核」，不能与实测值同款呈现；
4. `cover_asset=null` → 渲染占位，**不得**引用站外图片或本机路径；
5. 每个 `video_id` 必挂 `match_id` 或 `game_id`，且 `source_ref_id` 存在；
6. `file_name` 不符合 V4 命名规范 → 构建**告警**（不阻断，但列进待办）。

| 时长角标 | `duration_seconds` | 「待补」 |
| 「时长已确认 / 待复核」 | `duration_status` | 「待补」 |
| 封面框 | `cover_asset` | 虚框 + 「封面待补 · 16:9」 |
| 对应比赛 | `match_id` / `game_id` | 「待补」 |
| 片内时间码 | `clip_start_clock` / `clip_end_clock` | 「待补」 |
| 授权徽标 | `rights_status` | 「待授权」 |

## 5. 与主站集成方式

原则：**单一数据源 → 生成静态页**（`docs/04` 开头）。手写页只作样张，正式接入走生成器。

| 步骤 | 谁做 | 改什么 | 判定完成 |
|---|---|---|---|
| 1 数据 | 数据侧 | `videos[]` 进 `data/site_data.json`（或独立 `videos.json` + 校验）；`source_ref_id` 指向已有 `SourceRef` | `python src/prepare_data.py` 通过、schema 校验无缺引用 |
| 2 生成器 | 站点实现（非本任务） | `src/build_site.py` 加 `page_videos()`、`PAGES` 布局复用 `layout()`、把 `.vcover/.vdur/.vmeta` 搬进 CSS 常量；`site/videos.html` 由生成器改写 | 重新生成后页面与样张一致，`check_layout.py` 通过 |
| 3 入口 | 站点实现 | 首页「二级入口」卡片「视频与名场面」改为链接；是否加主导航「视频」**待 Jason 定**（`docs/01` §4.1：视频放二级入口） | 首页可点进，移动端底栏不受影响 |
| 4 资产 | 视频会话 + 运营 | 封面放 `site/assets/videos/*.jpg`（16:9，≤200 KB）；视频只放链接或压后的 web 版 | 无大文件进 Git；无站外图片引用 |

回滚：`videos.html` 与新增字段都是**增量**，删文件 / 关开关即回滚，不影响 `index.html`、`build_site.py` 现有产物。

集成后本文档的定位：从「方案」转为「字段与验收依据」；手写页保留作对照，不再手改。

- [x] 未确认字段 100% 带「待补 / 待授权 / 待确认」字样，无一漏标（全页 15 处「待补」）。
