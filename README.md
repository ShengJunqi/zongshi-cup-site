## 当前要做什么（M1）

只做 5 个页面/入口，**不批量生成全部选手页**：

1. 首页（公告与近期赛事、下一场/待公布、近期赛果、选手入口）；
2. 赛事详情页（公告、规则状态、简版赛程）；
3. 一篇真实单场战报（赏金赛第一把）；
4. 一个样板选手页；
5. 来源页。

交付时附 **320 / 390 / 430 三档手机截图** + **一张 1080×1440 分享卡**。

## 红线

- 不编战绩 / 胜率 / 奖金 / 日期；未确认写「待公布 / 待核实」。
- 只公开游戏昵称与游戏数据；不公开真实姓名 / 学校；选手可要求隐藏 / 删除。
- 已有赏金赛与未来赏金赛不是同一套规则；S1/S2 不自动解释为正式赛季。
- 未校准模型不叫「预测胜率」。
